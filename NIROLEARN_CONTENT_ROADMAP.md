# NiroLearn Content Roadmap

This roadmap builds real topical authority over time. It does not promise rankings, indexing, or AI citations.

## First 30 days

1. Publish and verify `/learn` hub.
2. Publish core entity page: `/learn/nirolearn`.
3. Publish reference guides:
   - `/learn/ai-study-guide`
   - `/learn/pdf-study-guide`
   - `/learn/flashcards-guide`
   - `/learn/exam-preparation-guide`
4. Publish protected question-set explainer.
5. Submit sitemap in Google Search Console and Bing Webmaster Tools.
6. Start measuring branded and non-branded impressions.

## 60 days

1. Expand Arabic clusters based on real Search Console queries.
2. Add deeper support articles only where there is unique intent:
   - AI study workflow
   - PDF to flashcards
   - PDF to questions
   - common flashcard mistakes
   - question-based revision
3. Add English pages only where independent query demand is clear.
4. Improve glossary with complete definitions and internal links.
5. Add official social/profile URLs to `sameAs` only after verification.

## 90 days

1. Expand reference guides with evidence-based sections and sources where needed.
2. Build more topic clusters around medical and engineering study if user demand appears.
3. Review pages with declining impressions or weak engagement.
4. Add IndexNow only if production configuration is ready and the trigger can be limited to changed public URLs.
5. Continue pruning or marking “do not target” for duplicate, confusing, or low-value queries.

## Measures

- Indexed pages
- Branded impressions
- Non-branded impressions
- Clicks
- CTR
- Query coverage
- Internal-link coverage
- Cited URLs and grounding queries where Bing exposes them
